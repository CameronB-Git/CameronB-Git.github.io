Invoice Dashboard
                

            

        

    


    
    

        

            

                
                
During my time at Ron Dearing UTC, I participated in a week-long
                    Work Experience placement at The 55 Group, a web development and
                    procurement-focused company based in Hull. This opportunity gave me hands-on experience working
                    within a
                    professional software development environment.
                

                

                

                    Throughout the week, our team followed a condensed version of an Agile Scrum
                        workflow,
                    covering stages such as project ideation, design, development, and testing.
                    We were introduced to modern JavaScript frameworks, including Node.js and
                    Vue.js,
                    alongside Tailwind CSS for responsive and efficient styling.
                

                

                

                    Using these technologies, we collaboratively built a fully functional
                    Invoice Dashboard — an application designed to allow users to manage, track,
                    and visualize invoices through a clean and interactive interface.
                

                

                

                    This experience gave me a deeper understanding of how frontend and backend systems integrate,
                    as well as exposure to team-based project management, documentation, and iterative development.
                    It was an invaluable introduction to the professional workflows and collaboration techniques
                    used in the industry today.
